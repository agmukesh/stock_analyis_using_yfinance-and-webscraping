📈 Stock Market Analysis using yfinance & Web Scraping

This project analyzes historical stock market data using the yfinance API along with web scraping to gather additional financial information from external sources. It demonstrates extracting real-time stock data, cleaning and preparing it for analysis, and generating meaningful visual insights that help understand stock performance, trends, and market behavior.

🔍 Project Overview

Fetches historical stock data (Open, High, Low, Close, Volume, Adjusted Close) using yfinance.

Scrapes additional financial or company-related information from the web to complement API data.

Cleans, transforms, and processes the combined dataset for deeper analysis.

Performs Exploratory Data Analysis (EDA) on stock price movements.

Visualizes stock trends such as closing price history, daily returns, and volatility.

Provides an easy-to-follow analysis pipeline for multiple stock tickers.

🧠 Key Features

Automated Data Collection: Pulls stock data directly from Yahoo Finance.

Web Scraping Module: Gathers additional metrics/articles from financial websites when needed.

Data Wrangling: Handles missing values, formats dates, normalizes columns, and merges scraped + API data.

Visualization: Line plots, moving averages, return charts, and trend analysis.

Reproducible Workflow: Just change the ticker symbol to analyze any stock instantly.
